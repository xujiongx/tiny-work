# 04 · 视觉与交互规范

- 版本：v0.1
- 关联：[产品设计](02-产品设计.md) · [技术设计](03-技术设计.md)
- 基调：**纸感、克制、耐看**。像一本每天都会翻开的办公笔记本，而不是一个数据看板。

---

## 1. 设计语言

现有 demo 已经有一套很好的底子：深墨绿侧栏、暖纸色内容区、衬线标题、等宽数字、陶土红强调色。工作台沿用这套语言，只做扩展，不推翻。

| 原则 | 表现 |
| --- | --- |
| 纸而非玻璃 | 不用毛玻璃、不用大面积渐变；用纸色、细线、留白建立层次 |
| 墨而非霓虹 | 强调色只用于“当前/重要/危险”，大面积用墨色与灰绿 |
| 数字要稳 | 时间、计数、统计一律等宽数字，避免跳动 |
| 分隔靠线 | 优先 1px 分隔线与留白，少用阴影和卡片边框 |
| 动效要短 | 120–180 ms，只做状态变化，不做装饰性动画 |
| 安静 | 不用红点、徽标数字轰炸、连续打卡火焰 |

### 1.1 关键词

`案头 / 纸 / 墨绿 / 陶土红 / 衬线 / 等宽 / 细线 / 留白`

## 2. 色彩

### 2.1 浅色主题（默认）

```css
:root {
  color-scheme: light;

  /* 基底 */
  --paper:        #e8e8df;   /* 页面底色 */
  --surface:      #f2f2e9;   /* 输入框、悬浮面板 */
  --surface-2:    #dcdcd1;   /* 选中态、表头 */
  --ink:          #1c211d;   /* 正文 */
  --ink-2:        #3a423b;   /* 次级正文 */
  --muted:        #5f675e;   /* 辅助文字（对 paper ≥ 4.5:1） */
  --faint:        #8a9187;   /* 占位符、禁用 */
  --rule:         #c4c8bc;   /* 分隔线 */
  --rule-soft:    #d6d9cd;   /* 更轻的分隔线 */

  /* 品牌 */
  --accent:       #b0472c;   /* 陶土红：当前项、关键动作 */
  --accent-deep:  #8f341d;   /* 小字号强调、hover */
  --accent-wash:  #e7d3c9;   /* 强调背景 */

  /* 侧栏 */
  --rail:         #17211b;
  --rail-2:       #223028;
  --rail-ink:     #e8e8df;
  --rail-muted:   #93a096;
  --rail-rule:    rgba(232, 232, 223, 0.14);

  /* 语义 */
  --ok:           #4f6b4f;
  --warn:         #a8792c;
  --danger:       #9c3a2a;
  --info:         #40566b;

  /* 标签（低饱和，避免争抢注意力） */
  --tag-moss:     #5c715e;
  --tag-clay:     #9c563e;
  --tag-ochre:    #8f6a24;
  --tag-indigo:   #40566b;
  --tag-plum:     #74485a;

  /* 字体 */
  --serif: "Iowan Old Style", "Songti SC", "STSong", "Palatino Linotype", Palatino, Georgia, serif;
  --sans:  "Avenir Next", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Segoe UI", system-ui, sans-serif;
  --mono:  "SF Mono", Menlo, Consolas, monospace;

```

### 2.3 使用规则

| 颜色 | 允许用于 | 禁止用于 |
| --- | --- | --- |
| `--accent` | 当前导航项、主按钮、删除确认、逾期日期 | 大面积背景、普通标签 |
| `--ok` | 已完成勾选、成功提示 | “新增”按钮 |
| `--warn` | 阻塞标记、即将到期 | 普通统计数字 |
| `--danger` | 删除操作、错误 | 日常强调 |
| 标签色 | 项目/标签圆点、chip 左边线 | 整块背景 |

- 语义不能只靠颜色：阻塞同时有 `!` 或文字“阻塞”，完成同时有勾选图形。
- 正文与背景对比 ≥ 4.5:1；大字号（≥ 24px）≥ 3:1。
- 陶土红用于小字号时优先 `--accent-deep`。

## 3. 字体与排版

### 3.1 字体角色

| 角色 | 字体 | 用法 |
| --- | --- | --- |
| 展示/标题 | `--serif` | 页面标题、品牌、空状态标题、周报预览标题 |
| 正文/界面 | `--sans` | 绝大多数文字、按钮、表单 |
| 数据/时间 | `--mono` | 时间、计数、日期数字、代码、快捷键 |

### 3.2 字号阶梯

| Token | 大小/行高 | 用途 |
| --- | --- | --- |
| `display` | 34/1.08 serif | 品牌、空状态大标题 |
| `h1` | 26/1.2 serif | 页面标题（今日、记录…） |
| `h2` | 18/1.35 serif | 区块标题 |
| `h3` | 14/1.4 sans 600 | 小节标题、侧栏分组 |
| `body` | 15/1.6 sans | 正文、记录内容 |
| `small` | 13/1.5 sans | 辅助说明、表单提示 |
| `meta` | 11.5/1.4 mono | 时间、标签计数、快捷键 |
| `micro` | 10.5/1.3 mono + 0.06em 字距 | 全大写标签、图例 |

规则：

- 页面标题用衬线，正文绝不用衬线（长文阅读反而累）。
- 数字统一 `font-variant-numeric: tabular-nums`。
- 中文不使用斜体；强调用字重或颜色。
- 行宽控制在 68–76 个中文字符；周报预览可到 80。
- 段落间距 12px；列表项之间 10–14px。

## 4. 布局与间距

### 4.1 栅格

- 间距基数 **4px**，常用：4 / 8 / 12 / 16 / 20 / 24 / 32 / 48 / 64。
- 左侧栏：248 px（窗口 < 1100 px 时 216 px）。
- 内容区：`padding: 32px 40px 64px`，最大宽度 1080 px，居中偏左（`margin-right: auto`）。
- 今日页两栏：主列 `1fr`，侧栏 300 px，间距 32 px。
- 窗口 < 1080 px：侧栏折到主列下方；< 900 px：导航收成图标栏（P2）。

### 4.2 层级

| 层级 | 表现 |
| --- | --- |
| 页面底 | `--paper` |
| 区块 | 无背景，仅标题 + 分隔线 |
| 可交互面板（输入、下拉） | `--surface` + 1px `--rule` |
| 浮层（命令面板、抽屉） | `--surface` + 1px `--rule` + 柔和阴影 |
| 侧栏 | `--rail`，不使用阴影 |

阴影只用于浮层：

```css
--shadow-pop: 0 18px 40px rgba(16, 22, 17, 0.18), 0 2px 6px rgba(16, 22, 17, 0.08);
```

## 5. 组件规范

### 5.1 导航项（rail）

```text
● 今日
○ 记录        3
```

- 高度 36 px，左右 padding 12 px，圆角 6 px。
- 默认：`--rail-muted` 文字；hover：`--rail-2` 背景。
- 当前：文字 `--rail-ink`，左侧 2 px `--accent` 竖线，背景 `rgba(255,255,255,0.06)`。
- 计数用 `--mono` 11px，右对齐，只显示未完成数，不显示红点。
- 图标可选，首版用文字 + 2 px 圆点，减少图标资产。

### 5.2 按钮

| 类型 | 样式 | 用途 |
| --- | --- | --- |
| Primary | 背景 `--ink`，文字 `--paper`，高 34，圆角 6 | 保存、生成周报 |
| Accent | 背景 `--accent`，文字白 | 唯一主动作（如“开始回顾”） |
| Secondary | 透明底，1px `--rule`，文字 `--ink` | 次要操作 |
| Ghost | 无边框，hover 有底色 | 行内编辑、更多 |
| Danger | 文字 `--danger`，hover 浅红底 | 删除 |

- 圆角 6 px，不用胶囊（除标签 chip）。
- hover 只变背景/边框，不做位移。
- 禁用：`opacity: .45`，`cursor: not-allowed`，保留可读性。
- 按钮内图标 14×14，图标与文字间距 6 px。

### 5.3 输入框

- 快速记录使用“无边框大输入”：

```css
.quick-input {
  width: 100%;
  min-height: 52px;
  padding: 12px 14px;
  background: var(--surface);
  border: 1px solid var(--rule);
  border-radius: 8px;
  font: 15px/1.6 var(--sans);
  resize: none;
}
.quick-input:focus {
  outline: none;
  border-color: var(--ink-2);
  box-shadow: 0 0 0 3px rgba(28, 33, 29, 0.08);
}
```

- 占位符 `--faint`，不使用“请输入…”这类冗余文案。
- 行内编辑：去掉边框，底部 1px 虚线；保存后恢复。
- 错误：边框 `--danger` + 下方 13px 说明，不抖动（减少动效时尤其）。

### 5.4 标签 chip

```text
#文档   #对齐   + 标签
```

- 高 24 px，圆角 999 px，padding 0 10 px。
- 背景 `color-mix(in srgb, var(--tag-*) 14%, transparent)`；文字用对应深色。
- 可删除时右侧 10px `×`，hover 才显示。
- 最多展示 3 个，超出显示 `+2`；点击展开。
- 输入标签时用逗号/回车确认，支持上下键选择已有标签。

### 5.5 时间线

```text
18:12  ●  完成   写完需求文档初稿
        │        #文档  #工作台
17:40  ●  进展   和数据同学对齐字段
```

- 时间列宽 52 px，`--mono` 11.5px，右对齐。
- 圆点 7 px；竖线 1 px `--rule-soft`，连接相邻项；最后一项不画线。
- 类型色：完成 `--ok`，阻塞 `--warn`，想法 `--tag-plum`，会议 `--tag-indigo`，学习 `--tag-ochre`，进展 `--faint`。
- 内容默认 2 行截断，点击展开；链接自动识别（仅 http/https），用下划线而非蓝色。
- hover 行背景 `rgba(28,33,29,0.03)`，右侧出现编辑/删除图标（28×28 点击区）。
- 新插入项：120 ms 淡入 + 4 px 上移，不做弹跳。

### 5.6 复选框

- 20 px 圆环，1.5 px `--rule`；hover 变 `--ink-2`。
- 选中：背景 `--ok`，白色对勾，120 ms 缩放 0.9→1。
- 完成项标题加删除线，颜色 `--muted`。
- 点击热区 32×32。

### 5.7 区块标题

```text
今日待办                                3/5
────────────────────────────────────────────
```

- 标题 `h3` 或 `h2`，右侧计数 `--mono` 11.5px `--muted`。
- 下方 1 px `--rule`，与内容间距 12 px。
- 不使用卡片包裹。

### 5.8 统计卡

- 无边框，纵向排列：数值（28px mono/ serif）+ 标签（11.5px mono）。
- 数值与标签之间 4 px；卡片之间用 1px 竖线分隔。
- 不用彩色背景；趋势用 `↑ 12%` 文字 + `--ok/--warn`。

### 5.9 日历

- 7 列等宽，单元格 32×32，圆角 4 px。
- 今天：1 px `--accent` 边框；选中：`--ink` 背景 + `--paper` 文字。
- 记录强度：0 无点；1–2 `--rule` 小点；3–5 `--tag-moss`；6+ `--accent`（点大小不变，只变色，避免视觉噪音）。
- 非本月日期 `--faint`，仍可点击。
- 周一为每周第一天（可在设置改）。

### 5.10 热力图

- 单元格 10×10，间距 3 px，圆角 2 px。
- 5 级色阶：`--rule-soft` → `--accent-wash` → `#c98a72` → `--accent` → `--accent-deep`。
- 只显示最近 12 周；hover 显示原生 tooltip（日期 + 条数）。
- 图例在右下角：`少 ▢▢▢▢▢ 多`。

### 5.11 Toast

- 位置：底部居中，距底 24 px；宽自适应，最大 420 px。
- 背景 `--ink`，文字 `--paper`，圆角 6 px，阴影 `--shadow-pop`。
- 停留 3 s（带撤销的 5 s）；同一时间最多 1 条，新的替换旧的。
- 错误 toast 左侧 3 px `--danger`。
- `aria-live="polite"`；错误用 `role="alert"`。

### 5.12 抽屉 / 弹层

- 日报抽屉：右侧，宽 420 px，全高；背景 `--surface`；左侧 1 px `--rule`。
- 命令面板：居中，宽 560 px，最大高 60vh；顶部搜索框 48 px，结果区可滚动。
- 关闭：`Esc`、点击遮罩、点击关闭按钮。打开时焦点进入，关闭后回到触发元素。
- 遮罩 `rgba(23,33,27,0.28)`，不做模糊。

### 5.13 空状态

- 居中偏上，最大宽 360 px。
- 衬线标题 20px + 一句说明 13px + 一个 Ghost/Primary 按钮。
- 不使用插画（首版）；可用一个 1px 线条小图形（圆/方）作为视觉锚点。

## 6. 动效

| 场景 | 时长 | 曲线 | 说明 |
| --- | --- | --- | --- |
| hover / focus | 120 ms | `ease-out` | 只变颜色/背景 |
| 插入记录 | 160 ms | `cubic-bezier(.2,0,0,1)` | 淡入 + 4px 上移 |
| 删除 / 折叠 | 140 ms | `ease-in` | 高度与透明度 |
| 抽屉 | 180 ms | `cubic-bezier(.2,0,0,1)` | translateX |
| 命令面板 | 140 ms | `ease-out` | 透明度 + scale .98→1 |
| 勾选 | 120 ms | `ease-out` | 对勾缩放 |

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

禁止：弹跳（bounce）、无限循环动画、背景粒子、数字滚动动画。

## 7. 图标与插图

- 首版不引入图标库；使用 Unicode 几何符号（`○ ● ✓ × ‹ › ⋯ +`）和少量内联 SVG（14×14，`stroke: currentColor`，1.5px）。
- 图标必须配文字或 `aria-label`；纯图标按钮需 28×28 以上点击区。
- 不使用 emoji 作为功能图标（心情选择除外，且提供文字标签）。

## 8. 文案语气

- **简短、具体、不卖萌、不训导。**
- 空状态给下一步，不给感慨。
- 错误说清“发生了什么 + 怎么办”，不甩技术术语。
- 不使用“亲”“哦”“啦”等语气词；不使用感叹号堆叠。

| 场景 | 推荐 | 避免 |
| --- | --- | --- |
| 保存成功 | 已保存 · 18:42 | 保存成功啦！🎉 |
| 保存失败 | 没能保存，请检查磁盘空间。 | 未知错误 |
| 空时间线 | 今天还没有记录。写下第一句吧。 | 暂无数据 |
| 删除确认 | 删除这条记录？7 天内可在设置里恢复。 | 确定要删除吗？ |
| 收集箱空 | 收集箱是空的。想到什么先丢进来。 | 空空如也~ |
| 快捷键冲突 | 快捷键被其他应用占用，点击更换。 | 注册失败 |

## 9. 无障碍

- 所有交互元素可 Tab 到达；`focus-visible` 用 2 px `--accent` 外框 + 2 px 偏移。
- 页面结构使用语义标签：`nav`、`main`、`section`、`h1/h2/h3`、`ul/li`。
- 时间线的每条记录是 `article`，删除/编辑按钮有 `aria-label`（含内容摘要）。
- 表单 label 不可省；视觉隐藏用 `.sr-only`。
- 颜色不作为唯一信息载体（类型有文字，优先级有符号）。
- 键盘焦点不因重渲染丢失：更新列表后把焦点还给输入框或原元素。
- 错误与保存状态用 `aria-live` 播报。
- 支持 200% 缩放不横向滚动（内容区最小宽度 640 px 时折行）。

## 10. 实现约定

- 所有 token 放 `style.css` 顶部 `:root`；组件只引用变量，不写死颜色。
- 类名用语义化 BEM-lite：`.timeline-item`、`.timeline-item__time`、`.task-row.is-done`。
- 状态类统一 `is-*`（`is-active`、`is-done`、`is-overdue`）。
- 不写行内样式（动态色阶除外，用 CSS 变量 `--level`）。
- 优先使用 CSS Grid/Flex；不用 float；不用 `!important`（减少动效媒体查询除外）。
- 深色模式通过 `data-theme` 切换，组件不写两套样式。
- 打印样式（P2）：周报预览 `@media print` 隐藏导航与按钮，正文黑白。
