## 1. 设计原则

1. **一屏一事**：每个页面只有一个主动作。今日页的主动作是“记一笔”。
2. **默认值优先**：类型默认“进展”，项目取最近使用，日期取今天。用户可以什么都不选。
3. **渐进披露**：标签、耗时、优先级等放在次要行或展开区，不阻塞主流程。
4. **时间是最强的结构**：所有记录最终都能回到“某一天”，日历/时间线是主要导航。
5. **安静**：不用红点、不用连续打卡焦虑、不做全屏庆祝动画。统计用于自省，不用于施压。
6. **键盘可达**：所有高频动作都有快捷键；鼠标只是备选。

│                                          │  今天还没回顾 →  花 2 分钟      │

布局：两栏，主列 `minmax(0, 1fr)`，侧栏 300–320 px；窗口 < 1100 px 时侧栏折到主列下方。

交互细节：

- **输入即专注**：进入页面自动聚焦输入框（可通过设置关闭）。
- **提交**：`Enter` 提交；`Shift+Enter` 换行；输入框高度随内容增长（最多 6 行）。
- **提交后**：保留类型/项目选择（连续记录同一项目时不用重复选），清空文本，保持焦点，顶部出现一条 1.5 s 的“已记录 · 撤销”提示。
- **空输入**：`Enter` 不提交，不报错，输入框轻微抖动一次（尊重减少动效则改为边框闪烁）。
- **时间**：默认取当前时间；点击时间可修改（补记）。
- **编辑**：点击内容进入行内编辑，`⌘Enter` 保存，`Esc` 取消。
- **删除**：悬停显示“×”，点击后直接删除并显示 5 秒“撤销”；不弹确认框。
- **今日待办**：勾选有 200 ms 划线动画；完成后 500 ms 内可撤销；完成项折叠。
- **日报**：点击展开为右侧抽屉/全屏面板；保存后显示摘要。

### 3.9 设置页

分组：外观、记录、提醒与快捷键、AI 助手、数据、关于。

- 使用系统原生控件风格的单行设置项，不做卡片套卡片。
- 危险操作（清空数据）放在最底部，需输入“删除”确认。
- 显示数据库路径、大小、最近备份时间，并提供“在访达中显示”“立即备份”“导出全部数据”。
- AI 助手是可选分组：启用开关、接口地址、模型、API Key（系统钥匙串）、测试连接、保存设置和清除 Key。页面明确说明只有点击生成时才会发送所选范围的记录；Key 不写进数据库，也不会随 JSON 导出。

## 4. 关键流程

### 4.1 记录一条工作

```text
打开应用 → 今日页自动聚焦
   → 输入文字
   → （可选）选类型/项目/标签/耗时
   → Enter
   → 立即出现在时间线顶部
   → 1.5s 撤销提示
   → 输入框清空并保持焦点
```

失败分支：写入失败 → 保留输入内容 + 顶部错误条“没能保存，请检查磁盘空间” + 重试按钮。**绝不静默丢失输入。**

### 4.2 晚间复盘

```text
18:30 系统通知“该回顾今天了”
   → 点击通知，打开主窗口并定位日报
   → 点“从今日记录生成”或“AI 生成”
   → 补充阻塞/明日计划
   → 选心情/精力
   → 自动保存（800ms 防抖）
   → 今日页显示摘要
```

“从今日记录生成”是确定性规则；“AI 生成”会先打开可编辑预览，显示本次读取了多少条记录，确认后才回填，并保留撤销入口。

### 4.3 周五写周报

```text
⌘5 回顾 → 默认本周
   → 点“生成周报”
   → 后端按模板聚合（完成记录/任务、阻塞、项目分布）
   → 预览可编辑
   → （可选）点“AI 重写”，根据本期记录润色并保留人工补充
   → 点“复制” → 粘贴到飞书/邮件
   → （可选）导出 .md
```

AI 重写前会保留当前 textarea 内容；重写后用 toast 提供“撤销”，不会直接落盘，也不会覆盖已导出的旧文件。

### 4.4 收集箱清理（每天 1 次）

```text
任务页 → 收集箱
   → 逐条决定：今天做 / 定日期 / 删掉 / 转项目
   → 清空后显示“收集箱清空了”
```

### 4.5 找回一条记录

```text
⌘K → 输入关键词
   → 结果分组展示
   → 回车跳转到记录页并高亮该条
```

### 4.6 AI 生成（显式、可撤销）

```text
日报 / 周报 / 绩效点“AI 生成”
   → 未配置：提示去「设置 → AI 助手」，不发起请求
   → 已配置：显示本次读取的范围与记录数量
   → 调用用户配置的 OpenAI 兼容接口
   → 日报/绩效先展示可编辑预览；周报直接替换 textarea 并给撤销
   → 用户确认后回填，日报自动保存，绩效仍需点保存
```

## 5. 状态与边界

| 场景 | 处理 |
| --- | --- |
| 首次启动 | 欢迎页：一句产品说明 + 创建第一个项目（可跳过）+ 写第一条记录 |
| 无数据 | 每个页面有具体空状态与一个主动作，不显示空白表格 |
| 加载中 | 骨架屏仅在 > 200 ms 时出现，避免闪烁 |
| 保存失败 | 输入内容保留；错误条 + 重试；不关闭编辑器 |
| 断网 | 核心功能无影响；AI 生成不可用，会提示检查网络或接口地址 |
| AI 未配置 | AI 按钮先提示去「设置 → AI 助手」，不发起请求 |
| AI 超时/报错 | 保留当前输入，中文错误提示；可重试，不自动重试扣费 |
| AI 返回格式不对 | 不覆盖现有内容，提示重新生成 |
| 跨零点 | 默认按自然日；设置 4 点分界后，00:00–03:59 归前一天 |
| 补记 | 时间可改，日期可改；列表按 `entry_date` 分组 |
| 删除项目 | 记录/任务变“未归类”；不级联删除；二次确认 |
| 删除记录 | 软删除 7 天；撤销 toast；设置里可恢复 |
| 大量数据 | 时间线分页（每页 100 条）；统计单独查询 |
| 快捷键冲突 | 注册失败提示；保留应用内快捷键 |
| 输入法组合 | `compositionstart/end` 期间不响应 Enter 提交 |
| 多窗口 | 快速记录窗保存后，主窗口通过 `app.push` 刷新 |

## 7. 与现有 demo 的关系

- 保留：左侧深色 rail、纸色内容区、衬线标题、等宽数字的设计语言。
- 替换：demo 的“这台电脑 / 留给下次 / 浏览器标签做不到的事”三块内容。
- 迁移：现有 `store.json` 里的 `lines` 可作为一次性导入，生成到“收集箱”或指定日期记录（默认导入为“想法”）。
- 应用名与 `id`：建议新 `id`（如 `app.desktop.workbench`），避免与 demo 数据混用；若要复用旧数据，先导出。

## 8. 待确认的交互选择

1. 今日页侧栏是“待办优先”还是“概览优先”？暂定待办在上。
2. 时间线默认倒序（最新在上）还是正序（像日记）？暂定倒序，设置可切换。
3. 日报是右侧抽屉还是独立页面？暂定抽屉（不离开今日上下文）。
4. 周报是否允许“锁定”某一版，避免重复生成覆盖？P1 考虑版本快照。
5. 快速记录窗是置顶浮窗还是普通窗口？暂定置顶、无边框、失焦自动关闭（可设置）。
